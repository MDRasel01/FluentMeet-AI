## 2. Phase 1: MVP Scope (Version 1.0) — Must Have

The MVP focuses on proving the end-to-end capture, transcription, diarization, and language coaching loop with high reliability on Google Meet.

### Core MVP Deliverables:
1. **User Authentication & Tenant Scoping:** Email/password registration, login, JWT session management, and basic organization isolation.
2. **Chrome Extension (Manifest V3):** Side panel interface, Google Meet URL/DOM detection, participant list scraping, mandatory consent checkbox, dual-stream audio capture (tab + mic), and WebSocket binary streaming.
3. **Audio Ingestion & Storage:** WebSocket ingestion service, Redis chunk buffering, S3/MinIO WAV file assembly.
4. **ASR & Speaker Diarization Pipeline:** Speech-to-Text transcription with word-level timestamps and speaker clustering.
5. **Speaker-to-Participant Matching:** Correlating local mic audio and DOM speaking indicators to map acoustic clusters to real participant names (with `Unknown Speaker` fallback).
6. **Gemini AI Language Analysis:**
   - Grammar & Syntax Analysis (tense errors, prepositions, agreement).
   - Vocabulary Nuance Analysis (repetitive terms, executive phrasing recommendations).
   - Basic Fluency Metrics (WPM calculation, pause duration, filler word counts).
7. **Web Dashboard Core Pages:**
   - Page 01: Dashboard Overview (KPIs, Recent Meetings, Empty States).
   - Page 02: All Meetings Archive (Search, filter, status).
   - Page 03: Meeting Details.
   - Page 04: Interactive Transcript Viewer (Audio playback synced with text).
   - Page 05: Individual English Report (Mistake breakdown, audio excerpts).
   - Page 11: Billing & Usage (Stripe plan checkout, minute metering).
   - Page 12: Settings (Profile, Audio retention toggle, Data erasure).
8. **Compliance & Privacy:** Mandatory participant consent verification, explicit retention toggles, complete data deletion capability.

## 3. Phase 2: Version 1.1 Scope — Should Have

Expands platform compatibility, advanced acoustic modeling, and organizational reporting:

1. **Expanded Platform Support:** Official support and verified DOM scrapers for Zoom Web Client and Microsoft Teams Web Client.
2. **Acoustic Pronunciation Analysis Engine:** Phonetic alignment using acoustic models (e.g., Azure Speech or forced alignment wav2vec2) providing IPA guidance and phoneme error scoring.
3. **Page 06: My Performance:** Longitudinal 30/60/90-day progress charts and mistake mastery progress tracking.
4. **Page 07: Learning Center:** Dynamic 3-minute daily practice challenges generated by Gemini based on recent meeting errors.
5. **Page 08: IELTS-Style Practice:** Translating meeting metrics into estimated IELTS Band Scores (0.0 to 9.0) with official disclaimers.
6. **Page 09: Team Analytics:** Scoped, anonymized communication reports for Team Managers.
7. **Data Export:** Exporting transcripts and analysis reports as formatted PDFs and JSON archives.

---

## 4. Phase 3: Version 2.0+ Scope — Future Vision

1. **Desktop Native Companion App:** Electron / C++ native application capable of capturing desktop Zoom, Teams, and Webex audio without browser limitations.
2. **Real-time Live In-Call Prompts (Whisper Mode):** Subtle, live visual cues displayed in the side panel during a call (e.g., *"You've used 'actually' 4 times in the last 2 minutes"* or pacing alerts).
3. **Enterprise LMS & HRIS Integration:** Direct integration with corporate learning systems (Workday, Cornerstone, Degreed) and Slack/Teams bot notifications.
4. **Custom Company Lexicons:** Allowing enterprise admins to upload company-specific jargon and acronyms to prevent false grammar/vocabulary flagging.

## 5. Explicit Non-Goals for MVP (What is NOT Being Built in MVP)

To prevent scope creep and ensure delivery quality, the following features are **strictly out of scope for MVP v1.0**:

| Feature / Capability | Status in MVP | Reason for Exclusion |
|---|---|---|
| **Native Desktop App Capture** | ❌ Excluded | Requires complex OS-level virtual audio drivers; browser extension satisfies core web users. |
| **Real-time In-Call Feedback** | ❌ Excluded | Live streaming analysis introduces high cognitive distraction for speakers during meetings. |
| **Meeting Bot Joining Rooms** | ❌ Excluded | Users dislike intrusive bots joining corporate calls; extension provides privacy-first local capture. |
| **Mobile App (iOS / Android)** | ❌ Excluded | Virtual business meetings predominantly occur on desktop/laptop computers. |
| **Automated Speech Translation**| ❌ Excluded | Product focus is coaching English proficiency, not multilingual translation. |
| **Synthetic Fake Demo Data** | ❌ Excluded | Strict rule: New accounts display informative Empty States, not fabricated metrics. |
